# Native addon license index

These supplemental notices describe the native dependencies in the desktop Harness distribution. The package-level licenses already shipped with other native families (pdfjs, Playwright, LibreOffice, DeepSeek system addon, sharp wrapper, ripgrep, node-addon-require-builtin, and node-pty) remain in their original package directories and are not replaced by this index.

- [Canvas 1.0.11](canvas/README.md): original SBOM, pinned Skia and Cargo source notices, and complete MPL crate sources.
- [Koffi 3.1.1](koffi/README.md): original parent/vendor MIT notices and Unicode data attribution.
- [Sherpa-ONNX 1.13.8](sherpa/README.md): native dependency provenance, original notices, and included eSpeak GPL corresponding-source archives and build materials.
- [sharp/libvips](../sharp-libvips/README.md): native image codec/library notices and replacement instructions.
- [Portable Python](../python-runtime/README.md): original standalone runtime license set, Tcl/Tk and bundled data.

Exact component sources and hashes are recorded in each component's sources.json. Component coverage does not imply every source-tree build/test dependency is linked into the delivered binary. Original notice texts retain their own upstream copyright names and examples.
