# @deepseek-ai/dsh-experimental-inspector 0.2.1-alpha.2 license supplement

`LICENSE` is the complete unmodified MIT project text from official commit `1c6078dca6acafc71e8bfcb1ad57ac2e01b604e1`. The source package manifest at that commit matches this exact installed package name and version; its original text is included as `source-package.json`.

The exact npm archive was verified against both the installed lock's integrity digest and npm's published shasum. It lacks a root LICENSE and its README does not include the full project license. This supplement adds the full text without changing runtime code. Archive URL/hash, fixed source URLs, license hash and the evidence basis are recorded in `source-evidence.json`.

The inspector also contains 29 upstream Chromium/devtools/third-party license files. Each already-shipped file was compared byte-for-byte to the original npm archive; their hashes and paths are recorded separately. This MIT supplement does not replace or relicense those components.
