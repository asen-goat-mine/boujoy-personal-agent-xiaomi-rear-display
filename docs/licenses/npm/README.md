# Installed npm license coverage

`installed-package-notice-inventory.json` records all **887 installed package instances** inspected in the desktop package. The package manifests and retained original notice files were checked against both editions and match. Package instances include repeated nested dependency versions.

- 854 instances retain their published root notice files or original notice directory.
- 7 instances retain a complete MIT text in their published README (hash.js, isarray 1.0.0 copies, and data-uri-to-buffer).
- 6 instances are covered by the detailed buffers/native-library supplements linked in the inventory.
- 19 instances need the original or supplementary full texts supplied here.
- dijkstrajs retains its original named copyright/declaration/disclaimer and receives the complete standard MIT text alongside it.

The two `part-sources-*.json` files identify the 20 supplemented package/version groups, exact original upstream license locations where available, installed-file and archive-integrity checks, and original declared-license/author evidence. Every `centralPointer` in the inventory resolves to a delivered notice directory or document.

## Originals and supplementary standard texts

Original upstream LICENSE files and published README/declarations are copied unchanged. Some older npm packages publish a MIT/ISC declaration and author metadata but omit a standalone full text, and their corresponding source trees also omit that file. In those cases, `standard-texts/` supplies the complete SPDX-published standard text, clearly marked as supplemental. Its generic template placeholders remain template text; the package's actual author metadata and any original copyright notice are preserved separately. Missing original copyright years remain unspecified.

The historical `MIT/X11` metadata string is preserved literally for chainsaw. Both standard MIT and X11 reference texts are supplied to document that upstream wording. No replacement original notice or copyright date is fabricated. The `https` package contains only its published package metadata; its declared ISC text is supplied consistently without treating it as a separate TLS implementation.

Standard Webhooks' JavaScript library uses the fixed repository's `libraries/LICENSE`; the repository-root protocol-specification Apache text is a different scope. Brotli.js has a declared MIT wrapper, a fixed Google Brotli submodule license, and Google decoder files carrying their own Apache-2.0 headers, all preserved here. Saxes' original notice also retains its upstream SAX attribution. The DeepSeek inspector's 29 original Chromium-related notices remain in the installed package; its own missing MIT text is supplemented from same-version source.

These package records supplement the component notices elsewhere in `docs/licenses/`. They do not replace the copyleft notices, included corresponding sources, or reconstruction materials for native components. This inventory documents notice/source coverage, and does not assert a single license policy for all npm dependencies or legal certification of every possible combined-work boundary.
