# 语音：数据流与可选本机回退

录音和朗读由用户主动点击或请求时使用，配置向导不会自动录音或朗读。当前 `src/server.mjs` 向 `LocalVoiceService` 注入 DeepSeek 工具，`src/adapters/voice.mjs` 会先尝试官方 ASR/TTS：录音音频或待朗读文本可能发送到已配置的 DeepSeek 服务。**不能把当前语音功能描述为全程本地**。录音完成后得到可修改的文字草稿，尚未发送聊天消息，不等于音频没有经过云端。

不要仅根据“本机语音”旧名称、麦克风权限提示、`transcriptionReady` 或运行时文件存在就判断数据流和功能已经验收。需要严格本机处理的用户，在使用语音前应先核对当前实现和真实网络行为；本说明没有提供一个实际不存在的“本地模式”开关。无需语音时继续使用文字输入。

## 当前限制

- 主窗口只有用户点击录音按钮才请求麦克风。系统权限由本人完成；外部页面、嵌入 frame、宠物窗口不能使用主窗口麦克风许可。
- 转写输入不超过 8 MiB / 两分钟，支持的音频由后端按实际字节校验。朗读需为助理消息且文本长度不超过 5000 字。
- 官方转写若需要转换音频格式，仍可能需要 ffmpeg 和本机语音运行配置；没有准备这些依赖，不能承诺只配一个 API Key 就能完成全部录音格式。
- 本机转写回退需要 faster-whisper 模型和隔离 Python；官方失败且无本机环境时会报错。macOS 朗读回退依赖本机 `say` 对应语言声音及辅助进程环境。

## 从完整源码准备本机回退

分享包的可搬移基础 Python 不附 pip/ensurepip，也不包含完整语音模型与 ffmpeg，也没有承诺语音开箱可用。接收者希望启用时，在自己的完整源码目录准备；不要复制分享者的语音 runtime.json，它包含另一台电脑的绝对依赖路径。

先准备本人环境的 Python 3.10+、可用的 pip（支持 `--python`）、ffmpeg 与 ffprobe。依赖的下载/安装由接收者选择并授权，不在知识库中放运行环境。然后在本版源码根运行：

```sh
python3 scripts/prepare-voice.py
```

脚本将本机回退环境放在本版 DATA 的 `build-tools/voice`，安装 `faster-whisper==1.2.1`，从固定模型 revision 下载文件并核验模型摘要。可用 `--runtime /本人的/本版数据目录` 明确 DATA。准备过程需要网络下载软件/模型，不会读取并上传用户录音。

源码后端还需要 `BOUJOY_PYTHON` 指向本机可运行的辅助 Python；分享版已有其基础解释器。此脚本生成的 runtime.json 指向自己的依赖路径，不能打入公共源码或当成别人电脑的通用配置。启动后先使用无敏感内容的短音频测试录音、转写、可编辑草稿、取消与朗读；检查真实 provider 与错误状态。模型文件存在不等于麦克风、沙箱、转换和推理链路全都通过。

## 隐私与记录

本人决定是否使用云端语音，不要让 AI 将音频贴给其他服务来绕过本地失败。记录测试时只保留输入时长/格式、provider、成功或失败与必要错误类别，不复制原始音频、聊天正文、凭证或本机路径。

本说明依据当前代码说明准备方式，并非这两个公开版已经完成真实麦克风、云端 ASR/TTS 或本机回退测试的验收证明；以实际发布记录为准。
